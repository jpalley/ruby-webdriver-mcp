# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-10-14

### Added
- Initial release
- MCP server implementation using FastMCP with HTTP/SSE transport
- Selenium WebDriver integration with support for Chrome, Firefox, and Edge
- 12 MCP tools for browser control (navigate, find elements, click, send keys, etc.)
- 3 MCP resources for browser state (current URL, page title, session status)
- Rails integration via Railtie with generators and Rake tasks
- Standalone executable server
- Devcontainer support for Rails 8
- Console log retrieval functionality
- Comprehensive documentation and usage examples
